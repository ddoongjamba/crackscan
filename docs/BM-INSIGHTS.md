> 출처: `N0240160413.pdf` (드론+AI 균열 검출 논문), `OTKCRK230377.pdf` (시설물 안전진단 자동화 연구, 2023)

## 1. 법적 의무 시장 — 가장 큰 기회

「시설물의 안전 및 유지관리에 관한 특별법」에 의해 교량·터널·댐·항만·옹벽 등 기반시설물은 정기적으로 아래 3단계 검사를 **법적으로 의무** 실시해야 한다.

- **정기안전점검** — 정기적 육안 수준 점검
- **정밀안전점검** — 면밀한 외관조사 + 측정
- **정밀안전진단** — 제1종시설물 정기 실시 (가장 엄격)

**BM 포인트:**
- 현재 CrackScan이 타겟하는 건물 외벽보다 예산이 확보된 훨씬 큰 B2B 시장
- **안전진단전문기관** (법적 등록 업체)이 주요 고객이 될 수 있음
- 법적 의무이므로 경기 침체와 무관한 안정적 반복 수요 → 구독 BM에 최적

## 2. 시장 규모 및 성장성

| 지표 | 수치 |
|---|---|
| 유지관리 투자액 | 1999년 0.5조 → 2007년 1조원 (9%→15%로 비율 증가) |
| 정부 R&D 투자 | 2020~2027년 총 1조원 (4차산업혁명 건설기술) |
| 노후 교량 비율 | 공용 10년 이상 교량이 전체의 **70%** |
| 시장 전망 | "노후시설물 증가 → 보수보강 시장 크게 성장 예측" (보고서 직접 인용) |

→ 랜딩 페이지·투자 자료·세일즈 자료에 이 숫자들을 시장 근거로 활용 가능

## 3. 현재 시장의 Pain Point — CrackScan이 해결하는 문제

보고서가 직접 지적한 현행 안전진단 문제점들이 CrackScan의 가치 제안과 정확히 일치한다.

| 현재 시장 문제 | CrackScan 솔루션 |
|---|---|
| 점검자 주관에 의존 — 같은 시설물도 점검자마다 결과 다름 | AI 기반 정량화 (균열폭 mm, 신뢰도 %, A~E 등급) |
| 보고서 형식 비표준화, 작성 수작업 | 자동 PDF 보고서 생성 |
| 전문 점검자 부족 | 사진 업로드만으로 즉시 분석 가능 |
| 첨단기술 존재하나 현장 활용도 낮음 — **도입 결정자가 기술을 모름** | SaaS — 가입 즉시 사용, 전문지식 불필요 |
| 고소·해상 등 사각지대 접근 어려움 | 드론 촬영 이미지 업로드로 원격 분석 |

**핵심 세일즈 메시지:**
> "Level 0 육안점검 → Level 2 AI 자동화 즉시 업그레이드"

(보고서의 자동화 Level 프레임워크: Level 0=육안, Level 1=아날로그 장비, Level 2=디지털+자동기록, Level 3=특정구간 자동화, Level 4=완전무인)

## 4. 확장해야 할 손상 유형 — Phase 3 우선순위

현재 CrackScan은 **균열(crack)**만 검출한다. 그러나 인프라 점검 국가 표준(국토안전관리원)에서 균열과 함께 필수 평가하는 손상 5종이 있다.

| 손상 유형 | 한국어 | 설명 |
|---|---|---|
| Spalling | 박락 | 콘크리트 표면 탈락 |
| Efflorescence | 백태 | 누수 흔적, 석회 침전 |
| Rebar exposure | 철근 노출 | 콘크리트 탈락으로 철근 드러남 |
| Water leak | 누수 | 수분 침투 흔적 |
| Surface damage | 표면손상 | 마모·충격·풍화에 의한 손상 |

**Phase 3에서 멀티 손상 검출 추가 시 B2B 계약 가능성 대폭 상승.**
→ Claude 프롬프트와 `CrackDetection` 인터페이스 확장으로 대응 가능

## 5. 타겟 시설물 확장 — 건물 외벽 → 법적 의무 인프라

균열이 핵심 평가 항목인 법적 점검 대상 시설물들. 현재 MVP(건물 외벽)에서 확장 시 우선순위 순서:

| 우선순위 | 시설물 | 균열 평가 기준 | 왜 기회인가 |
|---|---|---|---|
| 1순위 | 옹벽 | 균열 + 누수 | 고소차 접근 어려움 → 드론+CrackScan 대체 수요 |
| 2순위 | 교량 콘크리트 교각·교대 | A(0.1mm미만)~E(1.0mm이상) | 전국 교량 70% 노후화 |
| 3순위 | 터널 라이닝 | 종방향 균열, 망상균열 | 고소점검차 위험 작업 → 대체 수요 |
| 4순위 | 댐 콘크리트 구조 | 균열 + 누수 | 수중 접근 불가 사각지대 |
| 5순위 | 항만 콘크리트 | 균열 + 도장박리 + 부식 | 해상 작업 위험 |

## 6. 보고서 국가 표준 채택 — 강력한 차별화 포인트

현재 시장 문제: 점검 보고서 형식이 비표준화되어 점검기관마다 다름.

국토안전관리원 공식 손상 등급 기준(A~E):

| 등급 | 균열폭 | 의미 |
|---|---|---|
| A | 0.1mm 미만 | 안전 |
| B | 0.1~0.3mm | 경미 |
| C | 0.3~0.5mm | 보통 |
| D | 0.5~1.0mm | 심각 |
| E | 1.0mm 이상 | 위험 |

**CrackScan이 이 기준을 공식 채택하면:**
- "국토안전관리원 기준 준수 보고서" 마케팅 가능
- 안전진단전문기관이 법적 제출 문서로 활용 가능성 ↑
- 경쟁 서비스 대비 신뢰도 차별화

→ **오늘 구현한 `width_mm` + `severity`(safe/low/medium/critical) 분류가 이 A~E 등급 체계에 매핑됨. PDF에 A~E 등급 표기를 추가하면 완성.**

## 7. 드론 파트너십 — 채널 확장 기회

`N0240160413.pdf` (한국건설기술연구원 연구):
- 드론 + AI 앙상블(UNet, DeepLabV3) 균열 검출이 IoU 0.6 이상 달성
- **"계측 전문가 없이 진단 가능한 시스템은 연구 단계"** — 이것이 CrackScan의 포지션

현재 드론 검사 시장 상황:
- 드론으로 이미지 촬영은 가능해짐 (DJI 산업용 400만원~)
- 하지만 AI 분석 솔루션이 없어 검사 전문가가 수동 판독 중
- 드론 검사 업체들이 AI 분석 파트너를 필요로 함

**파트너십 모델:**
```
드론 검사 업체 → 이미지 촬영 → CrackScan API → 자동 분석 보고서
```
→ Enterprise API 플랜 + 화이트라벨 보고서 기능과 연결 (Phase 3~4 로드맵)

## 8. 디지털 트윈 / 이력관리 — Phase 4 방향 검증

보고서 최종 결론:
> "3차원 디지털 트윈 유지관리 플랫폼 — 외관조사망도, 손상 이력, 날짜별 비교. 향후 20년 내 도달 목표"

**CrackScan Phase 4 로드맵의 "건물별 검사 이력 관리, 날짜별 균열 비교"가 정부 연구에서 제시한 시장의 미래 방향과 정확히 일치.** 이 방향으로 가는 것이 맞다는 정부 연구 수준의 검증.
